# Theme — the AMS blog theme

The installable **Blogger (Google)** theme that makes every AMS post look like AMS: dark glass
surfaces, accent blue `#409CFF → #005CD6`, Inter typography — the same feel as the software and the videos.

| File | What |
|---|---|
| [`ams-blogger-theme.xml`](ams-blogger-theme.xml) | The theme. Upload it in Blogger and every post gets the AMS look. |

Production rules: [`engine/theme.md`](../engine/theme.md) · brand details: [`engine/BRAND.md`](../engine/BRAND.md).

## Install on Blogger

1. Blogger dashboard → **Theme**.
2. Click the **↓ / ⋮** menu next to *Customise* → **Restore** → **Upload**.
3. Choose `ams-blogger-theme.xml` → **Upload**.
4. Open the blog — every post (like [`../blogger/ams-capslock-osd/post.md`](../blogger/ams-capslock-osd/post.md)) now uses the AMS style.

## What it contains

- Dark `#06080F` background with blue glow accents
- Header with the **AMS** wordmark and tagline
- Responsive single-column post list (works on phones)
- Glass-card post body with Inter font, accent-gradient links and buttons
- Label chips, archive list, search box
- Footer: `© 2026 AMS` + YouTube link
