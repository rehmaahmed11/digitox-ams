# Engine spec — promotional video

How the engine produces a promo video. Brand rules: [`BRAND.md`](BRAND.md). Order: [`WORKFLOW.md`](WORKFLOW.md).

## Format (fixed, every video)

**65 seconds · 16:9 · 1920×1080 · 30 fps · H.264 (CRF 18) + AAC 256k 48 kHz · loudness −14 LUFS / −1 dBTP.**

Everything is **generated by code** (motion graphics drawn with **pycairo**, audio synthesized with
**numpy/scipy**, encoded with **ffmpeg**) — so every video can be rebuilt exactly or edited, shows the
*real* tool UI, and has no licensing issues.

## The 7-scene AMS structure

| # | Scene | Time | Purpose |
|---|---|---|---|
| 1 | **Hook** | 0–8s | The everyday pain in action (a relatable moment), ending on a short question in big text. |
| 2 | **Problem** | 8–18s | Lifestyle photo + 3 problem "chips" + a punchline (white + accent gradient). Builds to the reveal. |
| 3 | **Reveal** | 18–24s | **Hard cut.** Flash + boom, icon springs in, light rays, "INTRODUCING", **AMS ‹Tool›** + one-line tagline. |
| 4 | **Demo** | 24–36s | Realistic Windows desktop with the **real UI** of the tool, feature labels, then a zoomed beauty shot + caption. |
| 5 | **Features** | 36–50s | Title + 6 feature cards (3×2) appearing in time with the voice-over. |
| 6 | **Install** | 50–56s | "Up and running in seconds." 3 checked steps, AMS installer mock, badges. |
| 7 | **CTA** | 56–65s | Icon, title, tagline, **Download now** + **Subscribe to AMS**, YouTube URL, © AMS, fade out. |

Transitions: 0.5 s crossfade with a slight zoom; **hard cut at 18.0** (reveal impact).
Signature details: AMS corner logo from the demo through the install scene; tagline pattern *"Know your ‹thing›. Every time."*

## Voice-over

- Always the **official AMS voice** (masculine, confident advertising narrator, English).
- Match the reference clips: [`voice/ams-voice-reference.wav`](voice/ams-voice-reference.wav), [`voice/ams-voice-sample-demo.wav`](voice/ams-voice-sample-demo.wav).
- One clip per scene (`vo/s1`–`s7`), ~45 s of speech total, music breathing between lines; pause before the product name ("Introducing… AMS ‹Tool›.").
- Voice sits ~7–8 dB above the music; music ducks under speech.

## Music + SFX (synthesized in `audio.py`, no copyright claims)

- 120 BPM, A minor. Intro (0–18s): Am–F filtered pad + building pulse. Main: **Am–F–C–G** (pad, pluck arpeggios, bass, kick, claps, hats, sidechain). Final chord at 62s.
- Risers into the reveal (15.6→18) and the CTA (54.6→56); boom + shimmer at 18.0.
- SFX: key clicks, Caps "clack", chime up (ON) / down (OFF), error buzz, whooshes on cuts, pops on cards, dings on checkmarks.

## Images (AI, 16:9, no text, no logos)

3 per video: (a) frustrated person (problem), (b) abstract wallpaper (desktop demo), (c) premium desk/keyboard (CTA). Prompts are saved in each video's `README.md`.

## Files produced (one folder per product)

```
promotional-video/<tool>/
├── README.md           storyboard, VO script, image prompts, audio design, decisions
├── timeline.py         ALL timings — single source of truth (scenes, VO starts, presses, cards, cuts)
├── render.py           renderer: helpers → components (OSD/icon/keycap/windows/pills) → one function per scene
├── audio.py            music + SFX + VO mix → mix.wav
├── build_video.sh      audio → stills → frames → output/AMS_‹Tool›_Promo.mp4
├── vo/  img/  stills/  output/
```

## Rebuild / review

```bash
./build_video.sh                      # full build (~2 min)
python3 render.py still 26.4 35.0     # review single frames -> stills/
```

## Decisions that never change

- **Code-generated motion graphics**, never stock footage: the real UI is shown exactly.
- **Synthesized music**: zero copyright claims on YouTube.
- Fonts **Inter / Inter Display** (brand fonts).
- The demo uses the same UI design and motion timings as the real app (hold extended to 1.6 s for readability).
- A slow camera zoom in every scene so nothing is ever completely static.
