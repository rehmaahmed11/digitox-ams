# Mobile software

Apps for **Android / iOS** land here — one folder per product, same layout as [`../pc`](../pc):

```
software/mobile/<tool>/
├── README.md          what it does, tech chosen, how to build
├── src/               the app project
├── assets/            icon, screenshots, store graphics
└── release/           built artifact + store listing draft
```

*No mobile tool has been produced yet.* When one is, the engine writes it here following
[`engine/software/mobile.md`](../../engine/software/mobile.md) and the brand kit [`engine/BRAND.md`](../../engine/BRAND.md).
