# Blogger / Google posts — produced articles

Each AMS product gets a **ready-to-publish post** for the AMS blog on Blogger (Google).

| Folder | Product | File |
|---|---|---|
| [`ams-capslock-osd/`](ams-capslock-osd) | AMS Caps Lock OSD | [`post.md`](ams-capslock-osd/post.md) |

The writing rules live in the engine: [`engine/blogger.md`](../engine/blogger.md).
The blog's look lives in [`../theme/`](../theme).

## Publish a post
1. Open the product's `post.md`.
2. Copy the **SEO title** and **meta description** into the Blogger post settings; add the **labels**.
3. Copy the body into the Blogger post editor (HTML view), fill in the download/YouTube links, publish.
