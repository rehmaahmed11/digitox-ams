# AMS Caps Lock OSD — Promo Video

**Output:** `output/AMS_CapsLockOSD_Promo.mp4`: 65 s · 1920×1080 · 30 fps · H.264 CRF 18 · AAC 256k 48 kHz · −14 LUFS.

Everything is generated by code (motion graphics drawn with **pycairo**, audio synthesized with **numpy/scipy**, encoded with **ffmpeg**), so the video can be rebuilt exactly or edited.

## Rebuild
```bash
../../../engine/setup/setup_linux.sh   # once
./build_video.sh             # audio -> stills -> frames -> output/AMS_CapsLockOSD_Promo.mp4  (~2 min)
python3 render.py still 26.4 35.0   # render single preview frames to stills/
```

## Files
| File | Role |
|---|---|
| `timeline.py` | **Single source of truth for timing**: scene boundaries, voice-over start times, typing schedules, key presses, card/check times, cuts |
| `render.py` | Renderer: helpers (text, shadows, gradients), components (OSD popup, app icon, keycap, windows, taskbar, pills, callouts, icons) and one function per scene; crossfades between scenes; 2 parallel workers |
| `audio.py` | Music (pad, plucks, bass, kick, clap, hats, sidechain), risers, SFX, voice-over placement, ducking, fades → `mix.wav` |
| `build_video.sh` | One-command build |
| `vo/s1–s7.wav` | Voice-over clips (official AMS voice) |
| `img/` | AI images: `frustrated.jpg`, `wallpaper.jpg`, `desk.jpg` |
| `stills/` | Review frames |

## Audio design
| Layer | Detail |
|---|---|
| Tempo / key | 120 BPM, A minor. Intro (0–18) alternates Am–F with a filtered pad and a pulse that builds from 8 s. Main section uses **Am–F–C–G**. |
| Main groove | Detuned saw pad, 8th-note pluck arpeggio, sine bass, kick on every beat, clap on 2 & 4, off-beat hats, sidechain pump |
| Transitions | Noise riser 15.6→18.0 into a boom + shimmer at 18.0; riser 54.6→56; final Am chord + kick at 62.0 |
| SFX | Key clicks for every typed character, Caps "clack" on presses, chime up (ON) / down (OFF), error buzz, whooshes on cuts, pops on feature cards, dings on install checks |
| Mix | Voice EQ (HP 80 Hz + presence), music ducked about 62% under the voice (voice about 7–8 dB above music), soft-clip master, 0.4 s fade-in / 1.6 s fade-out, final loudnorm −14 LUFS / −1 dBTP |

## Decisions
- **Code-generated motion graphics** instead of stock footage: shows the *real* app UI exactly, keeps everything editable and rebuildable, and has no licensing issues.
- **Synthesized music**: no copyright claims on YouTube.
- Fonts **Inter / Inter Display**: modern and clean, close to Windows' Segoe UI.
- The demo uses the same OSD design and timings as the app (fade 170 / 420 ms; hold extended to 1.6 s for readability).
- A slow camera zoom in every scene so nothing is ever completely static.
